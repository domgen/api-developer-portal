Quote

Quote POST

Creates and returns a list of prices without person information

path Parameters
countryCode
required
string (CountryCode) <= 3 characters
Enum: "GBR" "AUS" "AUT" "BEL" "DNK" "FRA" "DEU" "IRL" "ITA" "NLD" "NZL" "POL" "PRT" "ESP" "SWE" "USA"
Example: USA

The 3 character ISO-3166 country code

header Parameters
X-User-Id
string <= 10 characters
Example: WHIRL

An ID of the person who has made the request and will be logged against the offer

X-Interaction-Id
string <= 10 characters
Example: WHIRL

A value which uniquely identifies the current customer journey and used for all calls to D&G APIs for that customer journey

X-Interaction-Direction
string <= 10 characters
Enum: "IN" "OUT"
Example: IN

A D&G code representing whether the interaction with the customer was triggered by the client [OUT] or by the customer [IN]

Request Body schema: application/json
required
required
object (CreatePersonData)
required
Array of CreateItemUsingModel (object) or CreateItemUsingAttributes (object)
required
object (Rating)

Responses

/v2/{countryCode}/client/quote
